Product One-Pager · social intelligence / simulation

用异质多 agent 市场模拟,做可验证、零泄露的预测

一群有信念、资本、信息差的 LLM「投资者」,它们的订单在集合竞价里撮合出一个涌现价格;每个交易日预测、第二天用真实结果打分。现做股票,方法可迁移到 polymarket 事件 / 调查。

对齐任务:在 social intelligence / simulation 方向,找一种可验证、可复现、可展示、可商业化的方法,系统性降低 AI 模拟与真实结果的误差——至少比裸 LLM、普通 agent survey、人工猜测、小样本更准。这一页正面回答:方向、差异化、做了什么、以及尚未解决的部分。
Q1

选什么方向?为什么?证据?

方向:不做「又一个回测很赚的 agent」,而做前向、零泄露的多 agent 市场模拟预测器——价格从一群异质 LLM 个体的订单流里涌现,每天对真实结果打分。

为什么(痛点):整个领域都在 backtest 上报「AI 很准」。但 LLM 有训练截止日——让它「预测」历史,它可能记得真实结果,这不是预测,是泄题。于是几乎所有结论都分不清「真 edge」还是「在背答案」。唯一可验证的检验是前向:预测一个做出时还不存在的未来,次日对账。这正是「可验证 / 可复现」的缺口,也是 leader 要的「方法论」而非创意 demo。

证据:

  • LLM 评测的训练数据污染是公认问题;走 out-of-sample / walk-forward 是金融 ML 的标准做法。
  • 我们的前向初跑已产出诚实数字(见 Q3):市场出清方向命中 80% > 群体平均 56% > 时序基准 60%——n 还小、不显著,但装置本身可复现地回答了「抹掉答案后还剩多少」。
Q2

竞品?用什么方法差异化提质?哪些论文证明有效?

竞品 / 现状
  • 裸 LLM「predict this」——无泄露控制、无打分
  • Agent-survey / silicon sampling——模拟 N 个 persona 取平均(是投票,不形成价格,且多为回测)
  • TradingAgents / StockAgent——学术多 agent 交易,回测,无前向泄露控制
  • 预测市场 / 民调聚合——靠真人,贵、慢、覆盖窄
我们的 4 个差异化方法
  • 前向零泄露 harness:预测明天、次日打分 → 灭训练数据污染
  • 价格从订单流涌现(集合竞价),非观点平均 → 资本加权、非线性、对分布敏感
  • 信息异质化(info_tier:散户/机构看不同信息)→ 建模真实信息不对称
  • 诚实打分 + 多基准对照(群体/市场/时序基准)+ 置信区间显著性标注

方法有效性的论文支撑:

· 多 agent 市场会涌现真实市场特征(肥尾、波动聚集):Lux & Marchesi (1999);Santa Fe Artificial Stock Market;TradingAgents;StockAgent (arXiv:2407.18957);Generative Agents, Park et al. (2023)。
· LLM 能逼近真实人群/调查(支撑向 polymarket/调查迁移):Argyle et al. (2023)「Out of One, Many」(silicon sampling 与真实民调高相关);Aher et al. (2023) LLM 复现经典人类实验效应。
· 时序基准:TimesFM, Das et al. (ICML 2024) 作为非 LLM 对照。

诚实地说:这些论文证明组件成立(ABM 涌现、silicon sampling 与民调相关),但没有一篇证明我们这套组合已经超越真实调查——那正是前向 harness 要持续回答的。

Q3

做了什么?什么指标?怎么测?说明了什么?

做了 (forward_v01,已上线):150 个独一 LLM persona × 5 只股票 / 天,信息分层 + 有符号影响力网络 + 集合竞价价格形成 + 每日 live 打分 + 3 predictor 对照 + 可交互看板(点开看每个 agent 的人设/信息/判断)。全链自动 cron。

指标(全前向、零泄露):方向命中率(Wilson 置信区间)、95% 区间校准率、平均绝对误差(MAE)。

怎么跑:walk-forward,本地 launchd 每交易日自动跑、次日评分,目前累积 ~10 个已评分观测(06-02→06-04)。

说明了什么:早期信号——「价格形成」比「观点平均」更接近真相(市场出清 80% > 群体 56% > 基准 60%),且修了波动率校准后区间 100% 命中。但 n=5~10 太小,命中率置信区间仍横跨 50%,统计上还不显著。

诚实结论:现在不能宣称「更准」;但已经有了 ① 一个能诚实、可复现回答这个问题的装置;② 一个值得追的早期方向性信号。这比「回测很赚」的不可验证结论更有价值。
